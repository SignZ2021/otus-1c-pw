#  Branch3
Ветка разработчика № 3

Поставлена задача разработки на основе нового отчета "Продажи по билетам" (см. [Branch2](https://github.com/SignZ2021/otus-1c-pw/tree/Branch2)) процедуры периодической выгрузки данных на внешний web-ресурс. Решение должно быть реализовано в виде расширения конфигурации 1С.

__Реализовано:__

_1) Создано расширение для конфигурации из ветки [Master](https://github.com/SignZ2021/otus-1c-pw/tree/Master) - "Отправка данных о продаже билетов":_
- в общем модуле _"ОДоПБ_ОбщийМодуль"_ реализована процедура _"ВыполнитьОтправкуДанных"_, которая работает на основе оптимизированного запроса из отчета "Продажи по билетам";
- в процедуре _"ВыполнитьОтправкуДанных"_ реализована серилизация данных результатов запроса в формат JSON и последующая отправка по указанному внешнему web-ресурсу;
- создано регламентное задание _"ОДоПБ_РегламентноеЗадание"_ для фонового запуска процедуры _"ВыполнитьОтправкуДанных"_ в указанное дату/время;
- создана обработка _"ОДоПБ_ТестОтправки"_ для тестирования и отладки процедуры _"ВыполнитьОтправкуДанных"_.
_2) Произведена отладка и настройка регламентного задания "ОДоПБ_РегламентноеЗадание":_
- введена константа _"ОДоПБ_ГлубинаОтчета"_ - для указания глубины вывода данных отчета в днях;
- введена константа _"ОДоПБ_ПутьКХосту"_ - для указания пути к хосту для отправки данных;
- по умолчанию, отправка данных настроена на каждое _воскресенье в 22:00_;
- для изменения настроек расписания выполнения регламентного задания в пользовательском режиме 1С:Предприятия может быть использована обработка  добавленная в конфигурацию разработчиком № 2 (см. [Branch2](https://github.com/SignZ2021/otus-1c-pw/tree/Branch2)).

Поставленные задачи выполнены. Доработанная конфигурация выгружена в текущую ветку разработок. Кроме файлов-исходников расширения в данной ветке выложено готовое к использованию в итоговом приложении расширение _ОтправкаДанных.cfe_.
