#  Branch2
Ветка разработчика № 2

Поставлены задачи доработки исходной конфигурации новым отчетом "Продажа билетов" и добавления обработки для работы с регламентными и фоновыми задачами.

__Реализовано:__

_1) Создан новый отчет "Продажи по билетам":_
- отчет реализован на основе технологии СКД;
- в его основе оптимизированный запрос к регистру накопления "Продажи";
- отчет интегрирован в подсистему "Продажи" и он доступен для использования в интерфейсе приложения.

_2) Добавлена новая обработка для работы с регламентными и фоновыми задачами:_
- данная обработка предназначена для настройки и проверки разработок 3-го разработчика (см. [Branch3](https://github.com/SignZ2021/otus-1c-pw/tree/Branch3));
- при разработке принято решение не использовать 1С:БСП для реализации требуемого функционала, из-за конфликтов при пересечении настроек пользователей и значительного увеличения размеров конфигурации;
- при реализации задачи использовалась разработка стороннего разработчика [JobsConsole2019.epf](https://github.com/kuzyara/JobsConsole2019.epf), созданная на основе обработки из 1С:ИТС и адаптированная для работы на тонком клиенте 1С;
- обработка интегрирована в подсистему "Администрирование" и она доступна для использования в интерфейсе приложения.

Поставленные задачи выполнены. Доработанная конфигурация выгружена в текущую ветку разработок.
