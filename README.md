#  Branch1
Ветка разработчика № 1

Поставлена задача доработки исходной конфигурации функционалом отражения статуса использования бонусов в документе "Продажа билета".

__Реализовано:__

_1) Программная доработка интерфейса формы фокумента "Продажа билета" для учета нового статуса:_
- при вводе бонусных баллов к списанию в документе после общей суммы выодится синяя надпись "Использованы бонусы";
- в остутсвии введенных бонусных баллов к списанию в документе после общей суммы выодится черная надпись "Бонусы не использованы"

_2) Программная доработка оформления списка документа "Продажа билета" для учета нового статуса:_
- с использованием условного офорления динамического списка документов произведена программная доработка выделения синим цветом документов использующих баллы при продаже билета.

Поставленные задачи выполнены. Доработанная конфигурация выгружена в данную ветку разработок.
