#  Branch1
Ветка разработчика № 1

Поставлена задача доработки исходной конфигурации функционалом отражения статуса использования бонусов в документе "Продажа билета".

__Реализовано:__

_1) Программная доработка интерфейса формы документа "Продажа билета" для учета нового статуса:_
- при вводе бонусных баллов к списанию в документе после общей суммы выводится синяя надпись "Использованы бонусы";
- в отсутствии введенных бонусных баллов к списанию в документе после общей суммы выводится черная надпись "Бонусы не использованы"

_2) Программная доработка визуализации списка документов "Продажа билета" для учета нового статуса:_
- с использованием условного оформления динамического списка документов произведена программная доработка выделения синим цветом документов, использующих баллы при продаже билета.

Поставленная задача выполнена. Доработанная конфигурация выгружена в текущую ветку разработок.
